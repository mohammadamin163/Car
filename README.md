این پروژه یک سیستم ساده برای مدیریت نمایشگاه خودروهای 
خارجی است که با زبان برنامه‌نویسی Python طراحی شده است
ثبت خودرو جدید: وارد کردن نام و قیمت خودرو و اضافه کردن آن به نمایشگاه.

نمایش خودروها: مشاهده فهرست تمام خودروهای موجود در نمایشگاه.

جستجوی خودرو: پیدا کردن خودروی موردنظر بر اساس نام آن.

فروش خودرو: حذف خودروی فروخته‌شده از فهرست خودروهای موجود.

نمایش قیمت خودرو: مشاهده قیمت هر خودرو.

مدیریت موجودی: بررسی خودروهای موجود در نمایشگاه.

پیام‌های راهنما: نمایش پیام موفقیت ثبت، فروش یا پیدا نشدن خودرو.

خروج از برنامه: پایان دادن به اجرای سیستم.





زبان برنامه‌نویسی: Python
