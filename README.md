 🚗 سیستم رزرو خودرو (Car Reservation System)

این پروژه یک سیستم ساده رزرو خودرو است که با زبان برنامه‌نویسی پایتون (Python) طراحی شده است.

این برنامه به کاربران امکان می‌دهد خودروهای موجود را مشاهده کنند، خودروی موردنظر خود را رزرو کنند و لیست خودروهای رزروشده را ببینند.

امکانات پروژه:

- نمایش خودروهای موجود
- رزرو خودرو
- نمایش لیست رزروها
- حذف خودرو از لیست خودروهای موجود پس از رزرو
- خروج از برنامه

ابزارها و مفاهیم استفاده‌شده:

- زبان برنامه‌نویسی Python
- لیست‌ها (Lists)
- حلقه While
- حلقه For
- دستورات شرطی If-Else
- دریافت ورودی از کاربر (Input)

نحوه عملکرد:

کاربر با انتخاب شماره گزینه موردنظر از منوی برنامه می‌تواند خودروهای موجود را مشاهده کند، یک خودرو رزرو کند یا لیست رزروهای خود را ببیند.

پس از رزرو موفقیت‌آمیز خودرو، آن خودرو از لیست خودروهای موجود حذف می‌شود.

هدف پروژه:

هدف از ساخت این پروژه، یادگیری و تمرین مفاهیم پایه برنامه‌نویسی پایتون و آشنایی با طراحی یک سیستم ساده مدیریت رزرو خودرو است.
